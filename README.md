# Dead-Vector
## What is Dead Vector
A space flight game written in C and OpenGL, built to fit in a tiny executable.
## Status
- Finished:
  - Basic rendering code
  - Relative camera movement & rotation
  - Mesh rendering
  - Sound engine (3D positional mixer with effects)
  - Cockpit view with mouse head-look
- In-progress:
  - Procedural mesh creation
  - Volumetric engine plumes and planetary rings
  - RCS thrusters for rotation
  - Mesh bytecode (meshes stored as small build programs instead of vertex data)
  - Rigid body collisions
  - Graphics rework:
    - Support for different light sources
    - Reflection FBO
    - Shadows
    - Texture support (including computer monitors)
    - Clean up rendering pipeline
    - Post-processing
  - Procedural HUD-like cockpit view
- To-do:
  - Plot
  - Asset modelling
  - Enemy AI
  - Procedural texturing
  - Many others
