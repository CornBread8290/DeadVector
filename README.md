# Dead-Vector
## What is Dead Vector
A space flight game written in C and OpenGL, built to fit in a tiny executable.
## Status
- Finished:
  - Basic rendering code
  - Relative camera movement & rotation
  - Sound engine
- In-progress:
  - Procedural mesh creation
  - Mesh rendering
  - Procedural texturing
  - Procedural HUD-like cockpit view
- To-do:
  - Plot
  - Asset modelling
  - Enemy AI
  - Many others
